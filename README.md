# TechSoft Reward System

A reward system for TechSoft S.A. that allows users to earn and redeem points through purchases.

## Features

- Register purchases and earn points (1 point per 1000 pesos)
- Check points balance
- Redeem points for cash value (1 point = 100 pesos)
- View purchase and redemption history
- User management

## Technologies

- Python 3.x
- Flask
- HTML5
- CSS3
- JavaScript

## Installation

```bash
# Clone repository
git clone https://github.com/AlexD335/RewardSystem.git
cd reward-system

# Install dependencies
pip install -r requirements.txt

# Run application
python app.py
